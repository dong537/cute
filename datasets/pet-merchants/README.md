# 中国宠物商家公开信源快照

此目录保存从第三方公开目录采集的**商家线索**，供编辑核查与后续数据处理使用。快照冻结于 **2026-11-26 11:22（北京时间）**，不是全国商家全量、在营商家名录或推荐排名。采集器仍在处理优宠网的大量详情页，后续结果不会自动写入这份快照。

## 数据文件

| 路径 | 内容 |
| --- | --- |
| `2026-11-26/merchants.jsonl.gz` | 压缩 JSON Lines，每行一条「来源站点＋商家 URL」记录 |
| `2026-11-26/merchants.csv.gz` | 相同记录的压缩 CSV，适合表格检查 |
| `2026-11-26/manifest.json` | 原始快照和发布文件的 SHA-256、字段与逐站计数 |

原导出有 101,621 条来源记录。发布版移除 50 条标记为个人或身份未核实的寄养记录，并保守排除 95 条名称含家庭/个人寄养字样但身份未明的记录，剩余 **101,476 条**：优宠网 94,173、萌宠网 3,800、爱宠网 2,308、八公 992、动物星球 203。跨站仍可能重复，未做实体合并；名称筛选可能同时排除少量真实商家。

发布版保留名称、目录页 URL、来源 URL、公开营业地点、营业时间、类别、服务及其他事实字段；移除电话、描述、图片 URL、精确地图坐标，以及详情事实中的联系人、法人、联系方式和个人证件标识。企业许可编号等商业事实仍可能保留。原始观察日志不发布。字段为来源页面的陈述，不代表本项目已核实。原有 `verified` 和 `license_verified` 值保持不变；这两个字段在本快照中均为 `false`。项目方已确认公开再分发授权，但本仓库未独立审计逐站授权证据，也未向下游授予额外数据使用许可。

在仓库根目录用 Node.js 解压 JSONL：

```powershell
node -e "const fs=require('node:fs'),z=require('node:zlib');fs.writeFileSync('merchants.jsonl',z.gunzipSync(fs.readFileSync('datasets/pet-merchants/2026-11-26/merchants.jsonl.gz')))"
```

使用前应按 `source_site`、`merchant_url` 回查原页，并核验商家身份、服务、地址、价格和营业状态。不要把原站评分或平台核验文字当作本项目的独立认证。CSV/JSONL 是采集时点的快照，不会随原网站变化自动更新。

CSV 为防止表格软件把文本当公式执行，会给以 `=`、`+`、`-` 或 `@` 开头的文本加前导单引号；JSONL 保留原文本。少数名称或地址在两种格式中因此会相差一个单引号。

采集与发布脚本位于 `scripts/pet-sources/`。安装依赖及运行测试：

```powershell
cd scripts/pet-sources
npm ci
node --test
```

重新生成快照时，用已授权、冻结且经内部审计的 `merchants.jsonl` 作为 `build-public-snapshot.mjs --input`；输出到新的空目录。原始 `observations.jsonl`、抓取日志、接力脚本和本机路径不属于公开数据包。
